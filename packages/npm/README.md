# avelra

Avelra UI is a desktop framework for web-native apps: web UI, a tiny native
runtime, instant builds, and sidecar extensions without a heavy runtime.

This package contains the `avelra` CLI and the native SDK payload for the
current platform. It is a technical preview; see https://avelra.dev for status.

Local install (the binary is under `node_modules/.bin`):

```bash
npm install avelra
npx avelra init my-app
```

Global install:

```bash
npm install -g avelra
avelra init my-app
cd my-app
avelra run
```
