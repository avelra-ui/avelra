# Avelra 0.4.2

Patch release for deb package metadata.

## Fixed

- Avelra SDK `.deb` packages now use `Avelra <contact@avelra.dev>`.
- Application `.deb` packages use `maintainer` from `avelra.config.json`.
- A missing or malformed application maintainer stops the build instead of
  inventing an author.
- The starter config exposes the `maintainer` field.

## Install

<https://avelra.dev/install/>

```bash
npm install -g avelra@0.4.2
```

## Verification

- SDK and application deb control metadata;
- missing-maintainer rejection;
- Linux build and full test suite;
- npm install/init/build on Node 22 and Node 24.
