# Avelra 0.4.1

Patch release for the 0.4 public preview.

## Fixed

- The starter application now links Examples to the public examples directory:
  <https://github.com/avelra-ui/avelra/tree/main/examples>.

## Install

The install flow is unchanged:

<https://avelra.dev/install/>

```bash
npm install -g avelra@0.4.1
```

## Verification

- Linux SDK and app template checks;
- npm install/init/build on Node 22 and Node 24;
- registry validation before `latest` promotion.

Linux x64 remains the public platform. Extensions remain planned for 0.5.
