# Avelra 0.4.0

**First public preview of the Avelra core on Linux x64.**

Avelra turns a web UI into a native desktop app. Bring React, Vue, Svelte or
vanilla frontends; Avelra runs the built static output in the system WebView
and adds a small native shell.

## Highlights

- public `window.avelra` core API;
- single executable per application;
- Linux tar and deb installers;
- npm package published as `avelra@0.4.0`;
- canonical user documentation and a five-distribution quality matrix;
- startup, CLI, app, desktop and UI checks passed before publication.

## Install

Start with the install guide:

<https://avelra.dev/install/>

Artifacts:

- [Linux tar.gz](https://github.com/avelra-ui/avelra/releases/download/v0.4.0/avelra-sdk-0.4.0-linux-x64.tar.gz)
- [Debian / Ubuntu .deb](https://github.com/avelra-ui/avelra/releases/download/v0.4.0/avelra_0.4.0_amd64.deb)
- [npm](https://www.npmjs.com/package/avelra)

```bash
npm install -g avelra@0.4.0
avelra init my-app
cd my-app
avelra run
```

## Requirements

- Linux x64;
- GTK 3.24+ and WebKitGTK 4.1;
- glibc 2.35+;
- Node.js 22+ for the npm launcher.

Verified targets: Ubuntu 22.04, 24.04 and 26.04; Debian 12 and 13.

## Verification

- checksums published with the release;
- install, CLI, app, desktop and UI checks on five Linux distributions;
- npm install/init/build on Node 22 and Node 24;
- post-release install from the published assets.

Details:

<https://avelra.dev/quality/>

## Scope

- Linux x64 is the public platform for 0.4.0.
- Windows and macOS SDKs and installers build in CI; their public rollout
  follows runtime and signing validation.
- Extensions and `window.avelra.callExt` are planned for 0.5.
- Fedora/RHEL-compatible systems use the portable tar; native RPM packaging is
  in development.
